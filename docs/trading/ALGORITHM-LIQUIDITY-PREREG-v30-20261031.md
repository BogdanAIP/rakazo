In detector at T, only original trades timestamped **<T**:

- Last 60s >= **5** genuine trade prints, recent contracts/min >= **3x** baseline contracts/min, absolute taker signed volume fraction >= **0.60** (80%+ same-side executed contract share).
- Signal direction `d = sign(B-S)`; global **60 minute source-time cooldown per instrument/date**, anchored on first eligible onset irrespective of outcome and regardless of L2 alignment. Log all raw qualified, suppressed and abstained minute decisions. No retuning to select winners.

- Recover authentic original **as-of top-five L2** book at `T-60s` and `T`, strictly before/same respective target; require prior original event <=5 sec old, a *subsequent* original event within 5 sec for time bracketing only; latter never enters the feature.
